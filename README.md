# 📊 Array & Data Analyzer

Интерактивное веб-приложение для анализа массивов данных. Находит все дубликаты элементов и их точные индексы (позиции) в массиве. 

Проект создан для демонстрации понимания алгоритмической сложности. Вместо классических, но медленных вложенных циклов (`O(N^2)`), здесь используется хэш-таблица, что позволяет обрабатывать данные за один проход — со сложностью **O(N)**.

## 🚀 Особенности
- **Интерактивный UI:** Можно вводить любые числа через запятую прямо на странице.
- **Оптимизация:** Линейная сложность алгоритма `O(N)` по времени.
- **Защита от ошибок ввода:** Встроенная валидация (фильтрация `NaN` и пробелов), если пользователь введет буквы или лишние запятые.
- **DOM API:** Рендеринг результатов происходит через безопасное создание узлов (`document.createElement`), без перезагрузки страницы.

## 🛠 Технологии
- **HTML5 & CSS3**
- **Tailwind CSS** (для быстрой и адаптивной стилизации)
- **Vanilla JavaScript** (логика парсинга и алгоритм поиска)

## 💡 Как это работает (алгоритм)
Скрипт проходит по массиву один раз. Каждое встреченное число становится «ключом» в JS-объекте, а в качестве значения туда записывается массив с его индексами. На втором этапе скрипт просто отфильтровывает те ключи, у которых длина массива индексов больше единицы.

## 💻 Как запустить
Проект полностью статический.
1. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/tyuzdeev/array-data-analyzer.git] (https://github.com/tyuzdeev/array-data-analyzer.git)
   ```
2. Откройте файл `index.html` в браузере. Никаких дополнительных сборок или серверов не требуется.
